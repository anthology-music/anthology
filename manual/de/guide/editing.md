# Tags bearbeiten

Redaktion und Administratoren können die Angaben der Bibliothek berichtigen: Titel, Künstler, Alben, Jahre, Genres, Komponisten und mehr.

## Bearbeitungsansicht

Stelle die **Ansicht** von **Hören** auf **Editieren**. Titel erhalten Kontrollkästchen; wähle die Titel aus, die du ändern willst, oder **Alle auswählen**, und wähle **Tags bearbeiten**. Auf einer Albumseite bearbeitet **Album bearbeiten** das Album selbst.

<Screenshot name="tag-editor" alt="Der Tag-Editor für ein Album" />

- Ein Feld mit **verschiedenen Werten** unter den gewählten Titeln bleibt unverändert, ausser du gibst einen Wert ein.
- Trenne mehrere Werte (zum Beispiel Genres) mit Kommas.
- **Titel in diesem Album** und **Künstler in diesem Album** ändern nur, wie ein Titel auf diesem Album erscheint; die Aufnahme behält ihren eigenen Titel.

Jedes Feld wird dort gespeichert, wo es hingehört: der Titel einer Aufnahme einmal für alle Alben, auf denen sie vorkommt, das Jahr eines Albums einmal für das Album. **Tags übernehmen** speichert die Änderung; grosse Änderungen laufen im Hintergrund.

Aus der Suche bearbeitet **Alle Ergebnisse bearbeiten** alle Ergebnisse auf einmal.

## Rückgängig und Verlauf

Der **Änderungsverlauf** listet jede Änderung mit Person und Zeitpunkt. Jede Änderung lässt sich rückgängig machen; Felder, die seither erneut geändert wurden, bleiben, wie sie sind, und werden gemeldet.

## Tags in den Dateien

Anthology hält die Angaben in seiner Datenbank und schreibt sie in die Dateien, die es verwaltet. Dateien, die in ihrem Ordner bleiben (referenziert), werden nur beschrieben, wenn das beim Import erlaubt wurde. Downloads und die Musik für die Lautsprecher tragen immer die Tags ihres Albums.
