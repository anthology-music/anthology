## Claude Code specifics

- Use the OpenSpec commands under `/opsx:` (generated by `openspec init` into `.claude/commands/opsx/`).
- For larger changes, plan first and get the OpenSpec proposal agreed before writing code.
- Prefer reading the affected `openspec/specs/<domain>/spec.md` over searching the whole codebase.
- Working in `server/` or `client/` loads that folder's `CLAUDE.md` (which imports its `AGENTS.md`).
